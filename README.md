# Random-scripts

[target-manager.zsh](https://raw.githubusercontent.com/Koustubha-naik/Random-scripts/refs/heads/main/target-manager.zsh)  : A simple Zsh tool to save, manage, and remove pentesting targets like IPs and hostnames.

**Setup**
```sh
curl -fsSL https://raw.githubusercontent.com/Koustubha-naik/Random-scripts/refs/heads/main/target-manager.zsh -o ~/.target-manager.zsh
echo 'source ~/.target-manager.zsh' >> ~/.zshrc
source ~/.zshrc
```
